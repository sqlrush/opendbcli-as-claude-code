OpenDB Landing Page — Two Approaches

Both use Cursor-style aesthetics (warm dark theme, generous whitespace, micro-animations). The difference is narrative structure.

Approach A: Terminal Story Arc
1. Hero — Live Terminal Animation
Typewriter effect: user types /llm → AI diagnosis unfolds in real-time
Tagline: "One agent. All databases. Zero complexity."
2. Three Modes — Interactive Tabs
Click tabs: Slash / SQL / Natural Language → terminal output switches
3. Six Features — Scroll-triggered Cards
/health → /dbtop → /sentinel → /scheduler → /rule → /llm
Each card: left=description, right=real terminal mockup with animation
4. Architecture Diagram
Three-layer visualization: Perception → Assessment → Diagnosis
5. Install + CTA
One-liner install + GitHub Stars + Apache 2.0
~5 sections, feature-by-feature deep dive

A. Terminal Story Arc

Core idea: Hero 区一个震撼的终端动画，然后逐个展示六大功能，每个都有真实输出

Strengths
  • DBA 看到真实输出立刻产生共鸣
  • 终端动画是独特的视觉锤
  • 叙事清晰：从"它是什么"到"它能做什么"
Risks
  • 六个功能逐一展示，页面较长
  • CTO 可能没耐心看完所有技术细节
Approach B: Problem → Solution Narrative
1. Hero — Problem Statement + Terminal
"Database is slow. Your pager fires." → OpenDB terminal appears, diagnoses in real-time
Emotional hook: every DBA's 3am nightmare
2. Before/After — Split Screen
Left: Traditional workflow (5 tools, 30 min) → Right: OpenDB (1 command, 2 min)
3. Core Capabilities — 3 Pillar Cards
Monitor (/dbtop + /sentinel) | Diagnose (/rule + /llm) | Act (/health + skills)
Each pillar: one key metric + one terminal screenshot
4. Why OpenDB — Value Props Grid
Multi-DB | Zero Deps | 273 Rules Offline | AI + Rules Hybrid | 60+ Skills
5. Install + GitHub + CTA
One-liner + Star button + "Join the community"
~5 sections, problem-driven narrative

B. Problem → Solution Narrative

Core idea: 从 DBA 的痛点切入，展示 OpenDB 如何用一条命令解决传统需要 30 分钟的问题

Strengths
  • 情感共鸣强：DBA 都经历过半夜被叫起来排障
  • Before/After 对比直观震撼
  • CTO 能快速抓住核心价值（降本增效）
Risks
  • 功能展示不够深入（三个 pillar 压缩了细节）
  • Before/After 对比需要精心设计才不显得老套

My recommendation: Approach A. OpenDB's terminal output is genuinely impressive — it IS the product. Showing real /dbtop dashboards, /llm multi-round diagnosis, and /rule millisecond results creates more "wow" than any marketing copy. The terminal animation in the hero section will be the visual differentiator that no other database tool has.
