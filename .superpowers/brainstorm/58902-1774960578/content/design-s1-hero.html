Design Details

Animation
  • Terminal appears with fade-in + subtle float-up (2px)
  • Command types out character by character (~50ms/char)
  • Output lines appear sequentially (~200ms delay each)
  • Root cause and fix blocks slide in from left
  • Animation replays on loop (pause 3s between)
Color System
  • Background: #0a0a0a (warm near-black)
  • Primary text: #edecec (warm off-white)
  • Secondary: rgba(255,255,255,0.5)
  • Terminal green: #7ee787 (success/prompt)
  • Warning yellow: #ffc61c (progress)
  • Alert orange: #ff6b35 (root cause)
  • Brand blue glow: rgba(6,82,122,0.15)
