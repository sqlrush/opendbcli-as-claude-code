## 场景设定

```
规模：1200 个数据库节点
  ├── 区域 A（华东）：300 节点（Oracle×120 + MySQL×180）  → Overlord-A
  ├── 区域 B（华北）：300 节点（Oracle×100 + MySQL×150 + PG×50）→ Overlord-B  
  ├── 区域 C（华南）：300 节点（MySQL×200 + PG×100）     → Overlord-C
  └── 区域 D（海外）：300 节点（PG×300）                  → Overlord-D

Manager Agent：1 台
LLM：统一使用同一模型（所有层级一致）
危险操作黑名单（Manager Agent 底线）：DROP TABLE / TRUNCATE / SHUTDOWN / DROP DATABASE
区域 B 追加：ALTER SYSTEM SWITCH LOGFILE（该区域 DBA 要求）
```
