## 紧急措施

立即创建索引（CONCURRENTLY 不阻塞业务）：

```sql
-- 先确认表存在及 uid 列类型
SELECT attname, typname 
FROM pg_attribute a 
JOIN pg_class c ON a.attrelid = c.oid 
JOIN pg_type t ON a.atttypid = t.oid 
WHERE c.relname = 'bench_t5' AND a.attname = 'uid';

-- 创建索引（不阻塞读写）
CREATE INDEX CONCURRENTLY idx_bench_t5_uid ON bench_t5(uid);
```

**⚠️ 风险评估**: CONCURRENTLY 模式不锁表，可在业务运行期间创建，但创建时间取决于表大小。

**📋 前置检查**: 确认表名正确（schema.bench_t5），确认 uid 列是否已有索引：
```sql
SELECT indexname FROM pg_indexes WHERE tablename = 'bench_t5';
```

**🔄 回滚方案**: 若索引创建失败或无效果：
```sql
DROP INDEX IF EXISTS idx_bench_t5_uid;
```
