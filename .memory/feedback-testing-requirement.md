所有功能开发完成后，必须在 Oracle 测试服务器上以人的视角验证。

**Why:** 源码分析不够，必须看到真实终端输出才能发现贴图错位、格式错误、数据异常等问题。

**How to apply:**
1. 使用 `opendb -c oratest <command>` 批量模式捕获每个命令的真实输出
2. 验证所有功能分支（包括正常路径、空结果、错误路径）
3. 检查：表格对齐、无 `<nil>`、无 panic、无列错位、中文显示正确
4. 以人看到的输出为准，不是源码推理
5. 验证结果保存到 docs/ 目录
